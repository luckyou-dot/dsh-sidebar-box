# 收纳盒（Sidebar box）

一个 DeepSeek Harness（DSH）左侧栏入口管理插件。

## 功能

- 在左侧栏「插件」下方添加「收纳盒」入口。
- 独立管理页从 DSH 侧栏注册表动态读取当前安装的功能入口，包括插件市场、搜索会话内容、回收站、SSH 等；新安装或启用的插件入口会自动出现在列表中，未安装的入口会标记「未安装」。
- 每个入口可在「显示」与「收进收纳盒」之间切换；设为常用的入口即使被收纳也仍显示在侧栏。
- 收纳后的入口只在管理页的「收纳盒预览」中查看，不添加到左侧栏「更多」菜单。
- 支持收纳盒内排序（拖拽或上下移动）、常用置顶、搜索、批量全选/收纳/显示/重置、显示名重命名。
- 所有设置保存在当前浏览器的 `localStorage`（键名 `dsh-sidebar-box:prefs:v1`），不上传任何数据。

## 使用

1. 点击左侧栏「插件」下方的「收纳盒」。
2. 在管理页把需要收起的入口设为「收纳」。
3. 管理页右侧的「收纳盒预览」会列出已收纳入口，点击即可打开对应功能。

## 界面设计

管理页采用「极简工作台」设计：浅灰蓝背景、白色圆角卡片、靛蓝与薄荷强调色、紧凑入口列表与右侧收纳盒预览；深色主题使用石墨底与柔和蓝紫强调。功能保持轻量，只保留入口收纳、排序与基础管理。

## 说明与限制

- 本插件只做「显示 / 收进收纳盒」二态，不提供彻底隐藏。
- 排序只影响管理页与右侧「收纳盒预览」的展示顺序，不改动左侧栏其他入口的原生顺序。
- 入口的显示状态与 DSH 原生的「固定/取消固定」是两套独立机制。
- 若某个入口对应的插件未安装或未启用，管理页仍会保留其设置，但无法打开。
- 显示名重命名会同步到左侧栏该入口的可见名称；原生权限或宿主重渲染后会自动重新应用。

## 安装

在 DSH 创造模式中由 Agent 通过插件管理器安装；源码目录即本文件夹。

## 卸载

在 **插件** 页卸载「收纳盒」。本插件不会删除浏览器 `localStorage` 中的设置；如需清除，可在浏览器控制台执行：

```js
localStorage.removeItem('dsh-sidebar-box:prefs:v1')
```
